# Mesa Regia — Frontend (Iteración 1)

Instrucciones para ejecutar localmente la interfaz inicial.

Requisitos:
- Un navegador moderno
- Servir los archivos por HTTP (import ES módulos y fetch requieren un servidor)

Comandos rápidos (desde la carpeta `frontend`):

Python 3 (simple):
```bash
python -m http.server 8000
```

Node (http-server):
```bash
npx http-server -c-1 . -p 8000
```

Luego abrir `http://localhost:8000` en el navegador.
